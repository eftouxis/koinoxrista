# Κοινόχρηστα πολυκατοικίας

Εφαρμογή διαχείρισης κοινοχρήστων: διαχειριστής και καρτέλα ανά διαμέρισμα.

- `index.html` – η εφαρμογή (GitHub Pages)
- `supabase.sql` – πίνακες και κανόνες πρόσβασης (RLS) για το Supabase

Ο κώδικας δεν περιέχει στοιχεία ενοίκων· τα δεδομένα βρίσκονται στο Supabase και κάθε διαμέρισμα διαβάζει μόνο τη δική του καρτέλα.
Το `supabaseKey` είναι το δημόσιο (publishable) κλειδί και προορίζεται για χρήση μέσα στην εφαρμογή.
